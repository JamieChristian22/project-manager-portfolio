# Lessons Learned

## Worked Well
Clear severity declaration accelerated ownership; identity prioritization focused containment; separating confirmed facts from hypotheses improved executive communication; evidence preservation supported analysis; recovery gates prevented premature restoration.

## Improve
Enforce MFA before incidents; monitor detection-rule health; establish identity baselines; automate common containment with approval safeguards; improve network/identity correlation; run credential-attack tabletop exercises; predefine legal/compliance triggers.

## Action
Every lesson is mapped to CAPA ownership rather than remaining a narrative-only observation.

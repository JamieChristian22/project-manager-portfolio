# MFA Remediation Plan

## Goal
Eliminate credential-only access for affected identities and prioritize privileged users.

## Steps
Inventory scoped accounts; confirm enrollment state; require approved MFA method; revoke legacy/session bypass where applicable; test login; document exceptions; escalate overdue enrollment.

## Metrics
Affected-account MFA coverage target: 100%. Privileged-account coverage target: 100%. Exceptions: zero without documented risk acceptance.

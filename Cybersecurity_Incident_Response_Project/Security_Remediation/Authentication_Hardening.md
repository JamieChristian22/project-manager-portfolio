# Authentication Hardening

Controls: MFA, smart lockout/rate limiting, stronger password policy, disabled legacy authentication where applicable, risk-based alerts, privileged-account separation, session revocation capability, periodic access reviews, and user notification for suspicious sign-ins.

Detection thresholds are tuned rather than blindly minimized: repeated failures by one account, one source targeting many accounts, distributed low-and-slow attempts, and success immediately following abnormal failures receive distinct correlation logic.

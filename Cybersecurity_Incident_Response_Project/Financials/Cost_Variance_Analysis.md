# Cost Variance Analysis

Baseline: $85,000. Scenario actual: $76,500. Favorable variance: $8,500 (10.0%). The largest overrun was investigation (+$900) due to expanded correlation of outbound telemetry; contingency absorbed this without exceeding baseline. Lower-than-planned recovery and documentation effort offset engineering increases.

Management conclusion: incident response remained within approved scenario funding while preserving contingency for unexpected escalation.

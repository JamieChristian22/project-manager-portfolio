# Incident Response Plan

## Workstreams
1. Command & governance: severity, decisions, action tracking, escalation.
2. Detection & investigation: log correlation, identity and network analysis.
3. Containment & eradication: accounts, sessions, indicators, access controls.
4. Recovery: restore users, validate integrity, heightened monitoring.
5. Communications: technical cadence and executive business-impact updates.
6. Remediation: control improvements, owners, dates, acceptance criteria.

## Decision Gates
Gate A: declare incident. Gate B: approve disruptive containment. Gate C: approve recovery. Gate D: approve closure. Each gate requires documented evidence, owner, and decision.

# Evidence Register

| Evidence ID | Artifact | Purpose | Handling |
|---|---|---|---|
| EV-01 | Authentication event export | Failure/success correlation | Read-only copy, timestamp recorded |
| EV-02 | SIEM alert snapshot | Initial detection evidence | Sanitized portfolio image |
| EV-03 | IAM/session activity | Account validation | Restricted scenario artifact |
| EV-04 | Network transfer summary | Outbound anomaly analysis | Aggregate values only |
| EV-05 | Containment action record | Prove response decisions | Change/action log |
| EV-06 | Recovery validation results | Closure evidence | Signed scenario checklist |

Evidence integrity rule: preserve originals, analyze copies, record timestamps and owners, sanitize screenshots, and never fabricate console evidence.

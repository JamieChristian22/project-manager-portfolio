# Cloud Cost Optimization Plan
- Enforce resource tagging for owner, project, environment and cost center.
- Review utilization weekly during project and monthly in operations.
- Right-size compute after 30 days of production metrics.
- Scale nonproduction capacity down outside required windows.
- Use S3 lifecycle rules where data-access patterns justify them.
- Review RDS utilization/storage growth and backup retention.
- Set budget thresholds and investigate anomalous spend.
- Consider commitment discounts only after workload baseline stabilizes.

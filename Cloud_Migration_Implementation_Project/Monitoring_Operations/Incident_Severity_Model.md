# Incident Severity Model
| Severity | Definition | Target response |
|---|---|---|
|Sev-1|Service unavailable/data integrity/security-critical|Immediate bridge/escalation|
|Sev-2|Major degradation; workaround limited|15 min acknowledgement|
|Sev-3|Partial/noncritical impact|Business-hours triage|
|Sev-4|Request/cosmetic/documentation|Backlog/prioritized queue|
During hypercare, Sev-1/2 incidents are reported to PM, App Owner, Cloud Lead and Operations immediately.

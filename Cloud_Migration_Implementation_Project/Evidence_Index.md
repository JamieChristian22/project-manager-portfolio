# Cloud migration: evidence index

This index lists files actually present in the project. Artifact presence does not prove execution in a live organization. Original PDFs and workbooks are retained as source snapshots.

## Review sequence

1. Read [the project case](Delivery_Case.md) for scope, decision rights, risks, and acceptance.
2. Open [the control exercise](Control_Exercise/README.md) for linked requirements, tasks, decisions, tests, budget, and gates.
3. Use the original artifacts below to compare the scenario narrative with its supporting files.
4. Read [the repository verification report](../verification/REPORT.md) for what was checked and what remains unverified.

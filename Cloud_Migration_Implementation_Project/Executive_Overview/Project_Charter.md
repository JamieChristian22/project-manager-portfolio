# Project Charter
**Project:** AWS Cloud Migration & Infrastructure Implementation  
**Sponsor:** VP, Technology (scenario)  
**Project Manager:** Jamie Christian  
**Start:** Week 1  **Target completion:** Week 12

## Purpose
Migrate the customer web workload from aging on-premises infrastructure to a secure, scalable, monitored AWS environment without unacceptable business interruption.
## Objectives
- Complete discovery and dependency assessment by end of Week 2.
- Establish AWS target environment by Week 5.
- Complete pilot and production migration by Week 9.
- Achieve 100% acceptance-test pass rate before production cutover.
- Complete hypercare and operational handoff by Week 11 and closure by Week 12.
## High-Level Scope
Assessment; architecture; landing zone; IAM; networking; EC2/ALB/Auto Scaling; RDS; S3; monitoring; backups; migration; testing; cutover; hypercare; documentation and training.
## Exclusions
Application feature redesign, enterprise-wide identity replacement, non-portal workloads, multi-region active-active architecture, and production procurement outside the scenario.
## Constraints
12-week delivery window; $125K cap; maintenance window limited to Saturday 10 PM–Sunday 2 AM; no Sev-1 open defect at go-live.
## Approval Gates
Charter → Architecture → Pilot exit → Go/No-Go → Operational acceptance → Closure.

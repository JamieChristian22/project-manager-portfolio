# Non-Functional Requirements

NFR-002 Availability ≥99.9%.  
NFR-003 Centralized monitoring/logging.  
NFR-004 Encrypted data transport.  
NFR-005 Role-based access.  
NFR-006 Automated backup and tested recovery.  
NFR-007 Scalable application tier.  
NFR-008 Maintainable deployment process.  
NFR-009 Auditable administrative actions.

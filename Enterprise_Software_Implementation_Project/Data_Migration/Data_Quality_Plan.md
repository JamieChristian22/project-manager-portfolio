# Data Quality Plan

## Quality Rules
- Required names present
- Valid email format
- Approved stage values
- Valid close dates
- Numeric opportunity amount
- Active owner mapping
- Duplicate review
- Relationship integrity

## Thresholds
Required-field completeness ≥98%; duplicate rate <1%; critical relationship errors = 0.

## Exceptions
Rejected records are logged with reason, owner, correction status, and final disposition.

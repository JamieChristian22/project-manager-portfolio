# Security & Access Model

## Principles
Least privilege, role-based visibility, separation of administrative responsibility, and controlled access.

## Roles
- Sales Rep: own/team-appropriate records
- Sales Manager: team visibility
- Sales Operations: broad operational visibility
- Salesforce Admin: configuration administration
- Executive: dashboard/report access

## Validation
Permission testing is included in SIT and UAT. No production release proceeds with unresolved critical access defects.

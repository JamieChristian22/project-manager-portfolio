# Reporting & Dashboard Design

## Leadership Dashboard
- Pipeline value by stage
- Opportunities by owner
- Forecast category
- Win/loss trend
- Aging opportunities
- Closing this month
- Data completeness

## Sales Manager Dashboard
- Team pipeline
- Rep activity
- Stalled opportunities
- Stage conversion
- Upcoming close dates

## Design Controls
Filters, date ranges, role-based access, and validation against source records.

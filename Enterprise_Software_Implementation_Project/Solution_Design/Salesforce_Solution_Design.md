# Salesforce Solution Design

## Core Objects
Accounts, Contacts, Leads, Opportunities, Activities, Users, Reports, Dashboards.

## Sales Process
Prospecting → Qualification → Discovery → Proposal → Negotiation → Closed Won/Lost.

## Key Configuration
- Opportunity stage probabilities
- Required close date
- Manager dashboard visibility
- Validation rules
- Role-based access
- Activity tracking
- Standard reports
- Executive dashboard

## Design Principle
Use standard Salesforce capabilities wherever possible to reduce technical debt and support maintainability.

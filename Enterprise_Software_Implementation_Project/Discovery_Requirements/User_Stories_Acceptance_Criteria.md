# User Stories & Acceptance Criteria

## US-001
As a sales representative, I want to create and update opportunities so that my pipeline is visible.

**Acceptance:** owner, account, stage, close date, and amount are captured when required.

## US-002
As a sales manager, I want a pipeline dashboard so that I can review value by stage and owner.

**Acceptance:** dashboard filters by owner, period, and stage and reflects approved opportunity data.

## US-003
As Sales Operations, I want validation rules so that reports are based on complete records.

**Acceptance:** required fields are enforced at the appropriate process stage.

## US-004
As a user, I want my approved legacy records available after go-live.

**Acceptance:** migrated records reconcile to approved source counts and maintain expected ownership.

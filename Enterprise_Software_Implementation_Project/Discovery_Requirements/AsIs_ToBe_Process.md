# As-Is / To-Be Process

## As-Is
Lead received → spreadsheet row created → rep follows up → opportunity tracked locally → manager requests updates → reports manually consolidated → forecast prepared.

## To-Be
Lead captured in Salesforce → qualification tracked → account/contact linked → opportunity created → standardized stage progression → activities logged → dashboards refresh from governed CRM data → managers review pipeline in real time.

## Process Controls
- Required fields
- Standard stages
- Opportunity owner
- Close date
- Stage probabilities
- Manager visibility
- Validation rules

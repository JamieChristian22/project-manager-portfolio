# Functional & Non-Functional Requirements

## Functional Requirements
FR-001 Configure Account and Contact objects.  
FR-002 Configure Lead management.  
FR-003 Configure Opportunity management.  
FR-004 Configure activity tracking.  
FR-005 Configure required sales stages.  
FR-006 Configure probability mapping.  
FR-007 Configure required fields and validation.  
FR-008 Configure roles and visibility.  
FR-009 Configure sales-manager reports.  
FR-010 Configure executive dashboard.  
FR-011 Support CSV-based approved data loads.  
FR-012 Provide record ownership mapping.

## Non-Functional Requirements
NFR-001 Role-based access must prevent unauthorized record visibility.  
NFR-002 Core pages should be usable within normal Salesforce performance expectations.  
NFR-003 Data import must preserve approved relationships.  
NFR-004 Auditability must support ownership and change review.  
NFR-005 User documentation must be available before launch.

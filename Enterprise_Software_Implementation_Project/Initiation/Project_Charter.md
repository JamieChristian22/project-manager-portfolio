# Project Charter

## Purpose
Implement Salesforce CRM to centralize sales data and improve opportunity management.

## Sponsor
VP of Sales.

## Project Manager
Jamie Christian, simulated Project Manager / CRM Implementation Lead.

## Objectives
Centralize sales data, standardize processes, migrate 12,500 approved records, train users, achieve ≥90% 30-day adoption, and reduce manual reporting.

## Success Criteria
- Go-live within 5% schedule variance
- Budget variance within 5%
- 0 open Sev 1 defects at launch
- ≥95% UAT pass
- ≥95% training completion
- ≥90% 30-day adoption
- 100% critical migration reconciliation

## Constraints
16-week delivery window, 75 users, fixed scenario budget, limited SME availability, and a single production cutover.

## Approval
Charter approved for the simulated project baseline.

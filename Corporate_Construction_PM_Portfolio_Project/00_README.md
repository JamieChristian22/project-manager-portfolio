# Corporate Construction Project Manager Portfolio Project

## Project: 75,000 SF Corporate Operations Center
This ZIP contains a **fictional, job-ready corporate construction project management simulation** built to demonstrate real PM controls from preconstruction through closeout. The scenario uses a $20.6M baseline budget, a January 2026 start, a March 2027 final completion target, and a September 11, 2026 status date.

## Files
- `01_Project_Management_Plan.docx` — charter, governance, RACI, scope, schedule, cost, changes, procurement, RFI/submittal controls, risk, safety, quality, communications, closeout and KPIs.
- `02_Executive_Status_Report_September_2026.docx` — management-ready status report with health indicators, KPIs, milestone forecast, cost/change narrative, top risks/decisions and next-30-day focus.
- `03_Closeout_Turnover_Lessons_Learned_Plan.docx` — closeout playbook, 90/60/30-day plan, punch, commissioning, financial closeout, lessons learned and final KPI scorecard.
- `04_Construction_PM_Project_Controls.xlsx` — integrated control workbook with dashboard, schedule, budget/forecast, procurement, RFIs, submittals, changes, risks, issues, safety, quality, stakeholders, actions and closeout.
- `05_Interview_Talking_Points.md` — how to explain the project credibly in interviews.
- `06_Project_Data_Dictionary.md` — definitions for key project-control fields and formulas.

## Core project story
At the September status date, the project is approximately **51.7% planned vs 49.9% actual**, creating a modest schedule variance. The principal short-term issue is the weather-tight milestone, driven by south-elevation framing/storefront sequencing and Area A MEP coordination. The project remains forecast within the revised budget, but the PM is protecting remaining headroom from elective changes and potential schedule-recovery costs. Major long-lead items have been released, with electrical gear remaining on the watch list. Safety has zero recordables.

## How to use it in a portfolio
1. Open the Excel dashboard first and explain what an executive sees in 60 seconds.
2. Walk into the Master Schedule and identify the critical near-term activities and recovery actions.
3. Show the Budget & Cost sheet and explain Revised Budget, ETC, FAC and variance.
4. Trace one issue across systems: e.g., RFI -> change -> budget code -> risk/action -> schedule.
5. Show Procurement for long-lead management and Submittals for release logic.
6. Explain safety/quality controls and how open findings are closed.
7. Finish with Closeout to demonstrate lifecycle ownership beyond construction execution.

## 👋 Project Overview

This portfolio project demonstrates how a Construction Project Manager manages a complex commercial construction project from **preconstruction through final turnover**.

The project was designed around the workflows, controls, documentation, decision-making, and executive reporting used in professional construction environments.

Rather than presenting isolated templates, the portfolio connects:

**Scope → Schedule → Cost → Procurement → RFIs → Submittals → Changes → Risk → Safety → Quality → Stakeholders → Commissioning → Closeout**

The objective is to demonstrate not only how project information is tracked, but how a Project Manager uses that information to **identify problems, make decisions, recover schedule, control cost, coordinate stakeholders, and protect project outcomes**.

# 🎤 Interview-Ready Project Story

### Situation

A simulated **75,000 SF, $20.6M corporate operations center** reached approximately the halfway point with actual progress trailing plan and multiple envelope, MEP, procurement, and contingency risks requiring coordinated PM action.

### Task

Protect the critical project milestones and final turnover while maintaining cost, safety, quality, procurement, and stakeholder controls.

### Action

I used CPM analysis to identify critical and near-critical work, developed a schedule-recovery strategy, implemented procurement escalation thresholds, drove RFI resolution, monitored change exposure against contingency, coordinated phased work releases, and consolidated project performance into executive reporting.

### Result

The management strategy established a controlled recovery path while maintaining the forecast within authorized project funding and preserving **zero recordable safety incidents** at the status date.

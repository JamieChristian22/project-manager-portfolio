# Access Control Matrix

| Role | Schedule | Patient Demographics | Reports | Admin |
|---|---|---|---|---|
| Scheduler | Create/update | Minimum needed | Limited | No |
| Front Desk | View/update selected | Minimum needed | No | No |
| Manager | View team | Limited | Yes | No |
| Clinician | View own schedule | Limited | Limited | No |
| System Admin | Support | Controlled | Yes | Yes |

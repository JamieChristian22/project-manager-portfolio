# Exception Workflows

## Cancellation
Cancel slot → reason logged → waitlist checked → slot offered → confirmation sent.

## Reschedule
Existing appointment selected → rule validation rerun → replacement slot booked → old slot released.

## No-Show
Appointment marked no-show → outreach task generated → history retained.

## Urgent
Priority request → urgency criteria checked → reserved slot or approved override used.

## Provider Unavailable
Affected patients identified → alternate provider/slot options generated → outreach tracked.

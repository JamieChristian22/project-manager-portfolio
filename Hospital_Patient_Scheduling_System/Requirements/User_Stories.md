# User Stories

## US-001
As a scheduler, I want to view valid available slots so I can book patients efficiently.

## US-002
As a department manager, I want utilization reporting so I can manage capacity.

## US-003
As a patient services user, I want cancellation and rescheduling workflows so that released capacity can be reused.

## US-004
As a privacy lead, I want controlled access and audit logs so sensitive scheduling information is protected.

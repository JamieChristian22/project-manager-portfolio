## Five-minute review

1. Read the README and distinguish simulations, demonstrations, and measured achievements.
2. Inspect tracked project deliverables using the paths below.
3. Open GitHub Actions and review completed results; scheduled or queued checks are not passed tests.
4. Reconcile inputs, calculations, and outcomes before citing business impacts.
